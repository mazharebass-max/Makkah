# Haramain Ride brand mark

Simple logo logic:

- **Twin pointed arches** — the Haramain (Makkah & Madinah)
- **Blue corridor curve** — the transfer / ride path
- **Orange destination dot** — arrival / booking accent

Files:

| File | Use |
|---|---|
| `haramain-ride-mark.svg` | Preferred crisp mark (header, footer, print) |
| `haramain-ride-mark.png` | Raster fallback / social / favicon source |
| `haramain-ride-mark.jpg` | Generated reference still |

Implemented in the site via `apps/web/components/BrandLogo.tsx`.
